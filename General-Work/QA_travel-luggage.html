No sound? / ¿No hay sonido?

Android: Settings → System → Languages & input → Text-to-speech output. Choose a speech engine and install English (US) voice data.
Ajustes → Sistema → Idiomas y entrada → Salida de texto a voz. Elige un motor de voz e instala los datos de voz en inglés (EE. UU.).

iPhone / iPad: Settings → Accessibility → Spoken Content → Voices → English. Download a voice. Make sure the silent switch is off and the volume is up.
Ajustes → Accesibilidad → Contenido hablado → Voces → Inglés. Descarga una voz. Asegúrate de que el interruptor de silencio esté apagado y el volumen alto.
